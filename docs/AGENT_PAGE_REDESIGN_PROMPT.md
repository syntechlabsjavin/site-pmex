## Common mistakes from past runs — do not repeat these
- Inventing a brand-new heading/eyebrow for a section that didn't have one before, just because the copied reference pattern includes one.
- Dropping a trailing period or small punctuation detail from an existing label while restyling it.
- Swapping an existing trust-badge/strip's real text content for a different reference page's badge content (e.g. replacing "Serving USA Clients / Proven Track Record / 1,200+ Satisfied Practices" with "AAPC Certified / BBB Accredited / Trustpilot" just because another page's badge row uses those) — only the CONTAINER DESIGN should be copied, never the other page's own words.
- Inventing a whole new section design (e.g. a dark-background section) when nothing in the approved reference pages actually uses that treatment — verify with grep first, every time.
- Applying a generic "add hover" pass without checking the EXACT hover class values (shadow size, duration, translate amount) against the real reference — wrong variants (e.g. `shadow-lg` where the reference uses `shadow-md`, `duration-200` vs `duration-300`) count as mismatches.
- Forgetting to re-add a local `<style>` block (like the last-card mobile-centering rule) when rewriting a section that depended on it.
- Claiming an icon/logo asset "doesn't exist" without actually checking dist/img/ — check first.
- Leaving a flex row of badge+text that wraps awkwardly on mobile — test narrow-width behavior (stack vertically or use `whitespace-nowrap` + wider padding as appropriate) for any custom badge/label combos you build.
