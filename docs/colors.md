# PMEX site colors (A to Z)

Ye list `dist/css/root.css` ke color variables se bani hai. **Sab colors sirf yahin define hote hain**, baaki puri site (root.css ke page blocks, `style=""` attributes aur page scripts) in ko `var(--c-HEX)` se use karti hai.

- **Naming:** `--c-HEX` solid color. Transparent colors ke naam ke aakhir mein `-a<percent>` (`-a12` = 12%, `-a10_2` = 10.2%). Har color ke liye 3 classes bhi hain: `.c-HEX` (text), `.bg-c-HEX` (background), `.bdr-c-HEX` (border).
- **Uses:** root.css ke page blocks, HTML aur page scripts mein `var(--name)` kitni baar aaya.
- **Brand names:** `--brand-primary`, `--brand-dark`, `--brand-light`, `--brand-tint`, `--brand-text`, `--brand-border`, `--brand-white`, `--brand-orange`.
- **Design tokens** (sirf in hi colors se bane): `--grad-*` gradients, `--shadow-*`, `--transition-*`, `--lift-hover`.
- **Total:** 475 color variables.
